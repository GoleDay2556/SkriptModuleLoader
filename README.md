# SkriptModuleLoader

**Lancasters Studios – Modular Skript Loader Plugin**  

SkriptModuleLoader is a **modular Minecraft Skript loader** that allows you to easily bundle `.sk` scripts with your plugin or drop external scripts into the loader. Works on **Minecraft 1.21+** and **Java 21**.

---

## Features

- Load `.sk` Skript files automatically from bundled resources  
- Supports external scripts in `plugins/SkriptModuleLoader/modules/`  
- Auto-copies scripts to `plugins/Skript/scripts/modules/`  
- Compatible with Paper / Spigot 1.21+  
- Fully modular and reusable  

---

## ⚙️ Requirements

- Minecraft 1.21+ (Paper or Spigot)  
- Skript plugin installed on server  
- Java 21 JDK (for building)  
- Apache Maven 3.9+ (for building)  

> Note: The server itself also requires Java 21 or newer.
